# Security policy

This repository contains documentation, structured data, and a static-site build. It is not a target list or an authorisation to test any linked organisation.

## Supported version

Only the latest release and the current `main` branch are maintained.

## Reporting a repository vulnerability

Use GitHub's **Private vulnerability reporting** feature if it is enabled for the repository. Do not open a public issue for a vulnerability that could affect users of the build workflow.

If private reporting is unavailable, contact the repository owner through the security contact listed in the published repository profile. Replace this paragraph with a dedicated security email before public launch.

Include:

- the affected file or workflow;
- prerequisites and impact;
- safe reproduction steps;
- a suggested mitigation, if known.

## Out of scope

- testing systems belonging to organisations linked as sources;
- reporting vulnerabilities in third-party websites through this repository;
- requests for operational hacking assistance;
- disputes about an article's opinion without a specific factual or source error.

For a terminology or source correction, use the public **Source correction** issue form.
