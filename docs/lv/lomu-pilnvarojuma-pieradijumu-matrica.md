# Loma, pilnvarojums un pierādījumi

Šī matrica nelemj, vai persona ir “īsts eksperts”. Tā palīdz saprast, kādā statusā tiek izteikts konkrēts apgalvojums.

| Loma | Tipiskā piekļuve | Pilnvarojuma avots | Pārbaudāms rezultāts |
|---|---|---|---|
| Red Team operators | Tvērumā ietvertas sistēmas, testa infrastruktūra, reizēm fiziski vai sociālās inženierijas scenāriji | Līgums un iesaistes noteikumi | Mērķu sasniegšanas pierādījumi, atklāšanas nepilnības, ziņojums |
| Penetrācijas testētājs | Noteiktas lietotnes, tīkli vai kontroles | Līgums un tehniskais tvērums | Reproducējami atradumi, riska novērtējums, ieteikumi |
| Blue Team / SOC analītiķis | Telemetrija, brīdinājumi, žurnāli, aizsardzības rīki | Darba pienākumi un organizācijas procedūras | Detekcijas, triāža, eskalācija, aizsardzības uzlabojumi |
| Incidentu reaģētājs | Žurnāli, tīkla plūsmas, galiekārtu dati, incidenta laika līnija | Incidenta vadības mandāts | Ierobežošana, izskaušana, atjaunošana, pēcanalīze |
| Digitālās kriminālistikas izmeklētājs | Diska un atmiņas attēli, artefakti, pierādījumu ķēde | Izmeklēšanas uzdevums un procedūras | Metodiski iegūti un analizēti pierādījumi |
| CTI analītiķis | Iekšējie un ārējie avoti, novērojumi, ziņojumi | Organizācijas izlūkošanas uzdevums | Avotos un pārliecības līmeņos balstīts novērtējums |
| Drošības pētnieks | Laboratorija, publiski avoti, politikā atļauti aktīvi | Īpašumtiesības, līgums vai programmas politika | Reproducējams pētījums vai ievainojamības ziņojums |
| Žurnālists | Avoti, intervijas, dokumenti, publiskie dati | Redakcionālais uzdevums un avotu aizsardzības principi | Pārbaudīts sabiedriski nozīmīgs stāsts |
| Ārējs komentētājs | Galvenokārt publiski paziņojumi un sekundāri avoti | Nav operacionāla mandāta, ja vien nav norādīts citādi | Skaidrojums, kurā atklāti avoti un nenoteiktība |

## Pareizais jautājums

Nevis: “Vai cilvēks izklausās pēc kiberdrošības eksperta?”

Bet:

> Kāda bija viņa loma, ko viņš drīkstēja darīt, kam viņš varēja piekļūt un kādi pierādījumi pamato konkrēto apgalvojumu?

Vienai personai dažādos brīžos var būt vairākas lomas. Svarīgi ir norādīt to lomu, kurā tā runā vai rīkojas konkrētajā situācijā.
